# Web-Prog
Выполнение дз и лабораторных работ по курсу (Суворин И.А.)

Лабораторная работа №2

1. Создание структуры проекта:
- Добавлены файлы index.html, script.js, style.css.
- Проверено подключение JS (вывод в консоль "Скрипт подключен и работает!").

2. Создание динамической структуры интерфейса:
- Вся разметка создаётся с помощью JS (без статического HTML).
- Реализованы блоки: header, форма добавления задач, панель фильтров, список задач, footer.

3. Добавление функционала добавления задач:
- Пользователь может вводить название и дату задачи.
- Дата необязательна, но теперь вводится в формате дд-мм-гггг.
- После добавления задачи очищаются поля ввода.

4. Редактирование, удаление и отметка задач:
- Возможность редактировать название и дату задачи.
- Добавлена проверка формата даты при редактировании (только дд-мм-гггг, без букв).
- Возможность отмечать задачи как выполненные или возвращать в активные.
- Возможность удаления задач из списка.

5. Фильтрация, поиск и сортировка:
- Фильтр по статусу (все/ выполненные/ невыполненные).
- Поиск по названию задачи в реальном времени.
- Сортировка по дате (возрастающая).

6. Сохранение данных:
- Все задачи хранятся в localStorage.
- При перезагрузке страницы список задач восстанавливается.
- Добавлена защита от ошибок при повреждённых данных.

7. Drag-and-drop:
- Реализована возможность перетаскивания задач мышкой для изменения их порядка.
- Новый порядок сохраняется после перезагрузки страницы.

8. Добавление стилей (CSS):
- Подключён style.css к index.html.
- Оформлены кнопки, поля ввода, список задач, ховеры.
- Добавлены базовые отступы, фон, стили для выполненных задач (перечёркивание, изменение цвета).
